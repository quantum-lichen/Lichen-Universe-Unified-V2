## 🔹 **1. Comprendre la Vision (5 min)**
### **Pourquoi Lichen existe ?**
- **Problème** : L’informatique moderne est basée sur des conventions arbitraires (ex: architectures Von Neumann, formats de données inefficaces).
- **Solution** : Utiliser des **constantes universelles** (comme le nombre d’or φ ou le nombre parfait 496) pour créer des systèmes **auto-stabilisés, résilients et zéro ambiguïté**.
- **Analogie** : Imagine un ordinateur qui "pousse" comme un lichen — il s’adapte, se répare, et dure 10 000 ans.

> *"On ne construit pas l’ordinateur. On le plante, et il pousse."* — Bryan Ouellette

## 🔹 **8. FAQ des Newbies**
### ❓ *"C’est quoi l’intérêt de Lichen par rapport à Python/TCP/IP/JSON ?"*
- **Vitesse** : ΦLang compile **4.5x plus vite** que Python.
- **Résilience** : FC-496 + CRAID = données **indestructibles** (même si 2 nœuds sur 5 crashent).
- **Universalité** : Conçu pour durer **10 000 ans** (stockage ADN) et communiquer avec des **civilisations extraterrestres** (langage mathématique pur).
- **Éthique** : Intègre des **gardes-fous thermodynamiques** (CEML, H-Scale) pour éviter les dérives.

### ❓ *"Je ne comprends rien aux maths. Puis-je quand même contribuer ?"*
**OUI !** Tu peux :
- Tester les démos et **remonter des bugs**.
- Créer des **tutoriels visuels** (ex: dessiner des glyphes LGL).
- Traduire la doc en d’autres langues.
- Participer aux **discussions philosophiques** (ex: éthique de l’IA).

### ❓ *"Comment exécuter du code ΦLang chez moi ?"*
1. Clone ce dépôt :
   ```bash
   git clone https://github.com/quantum-lichen/Lichen-Universe-Unified-V2
   ```
2. Installe les dépendances :
   ```bash
   pip install -r Languages/PHILANG/requirements.txt
   ```
3. Compile un fichier `.phi` :
   ```bash
   python -m philang compile ton_fichier.phi
   ```

*(Un guide détaillé est disponible dans [`ΦLang/README.md`](Languages/PHILANG/README.md).)*
